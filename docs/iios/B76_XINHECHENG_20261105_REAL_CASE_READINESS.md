# 新和成 002001：B76 真实案例输入就绪度审计

**审计日期：** 2026-11-05  
**案例：** `RC-CN-A-002001-20261105`  
**估值模型：** EPS_MULTIPLE  
**开发分支：** `feat/b76-core-integrated-20261101`  
**性质：** 真实公司披露事实的研究工作包；不是正式 Evidence/PIT admission、Forecast Admission、Valuation Admission 或投资决策。

## 1. 结论

新和成的基本财务事实并不缺。2025 年审计年报和 2026 年三季报已经提供了足够多的公司整体利润、现金流、业务收入成本、非经常损益和资产负债信息。

真正卡住 B76 的，是 B55 当前要求的历史物理经营基线：每条业务线都必须有历史销量、净售价、单位变动成本。2025 年年报披露了业务分类下的收入与营业成本，但这不是这三项物理量价成本数据。

**不能把营业成本直接重命名为单位变动成本。** 营业成本可能包含制造费用和折旧等项目；如果 B56 再次扣除固定费用或折旧，可能重复扣减利润。因此本案例必须继续保持 B55/B56/B57/B58 的阻断状态，不能为了跑出 EPS 而填入推算吨数或伪造成本拆分。

## 3. B55 到 B60 的逐项阻断

### B55：历史物理基线缺失

代码当前的 `_build_baseline_transition_bridge` 对每条历史业务线要求：

- `sales_volume_tonnes`
- `net_asp_cny_per_tonne`
- `variable_cost_cny_per_tonne`

公开年报提供了业务收入、营业成本，但本次核查的年报文本没有提供上述逐业务线历史吨数、净 ASP 和单位变动成本。因此 B55 必须返回 `NOT_IDENTIFIABLE` / `BLOCKED`，不能将收入除以自设售价反推历史销量。

### B56：不能绕过 B55

当前 B56 必须依赖 B55 已对账贡献，并单独核算固定现金费用、折旧摊销、融资成本和税率。若把营业成本当成变动成本，或把毛利再当作 EBITDA，会发生口径错配与重复扣减。

### B57：报告 EPS 不是未来 EPS

2026 年前三季度稀释 EPS 1.90 元是已实现九个月累计口径，不是 2026FY 或下一预测期间的前瞻 EPS。B57 仍需要 B56 前瞻利润、归属调整和前瞻加权平均稀释股数。年报/三季报当前提取结果包含两位小数 EPS 和期末股本，但没有可直接用于精确 B57 对账的情景加权平均稀释股数；不能用归母净利润除以两位小数 EPS 反推精确分母。

### B58：缺少同期间、同分母主 EPS 对照

没有合格的 B57 前瞻 all-items EPS，也没有同预测期间、同稀释股数和税后归属调整基础的主 EPS 对照，不能显示 MATCH 或 EPS 余量。

### B60：现价输入缺失

本轮不把旧案例中的 2026-10-07 价格上下文冒充 2026-11-05 现价。按 IIOS 操作员价格路径，等待操作员提供证券、观察日期和价格并形成声明；在此之前 B60 不运行。

外部 MIE 仍为 `NOT_IDENTIFIABLE`。B60 的价格条件反推也不会因此成为外部 MIE。

## 4. 正确的最小架构修正方向

不要放宽 B55，也不要添加大量“假设销量”字段。下一批建议只引入一条与物理驱动归因并列、但严格隔离的 **Public Financial-Statement Bridge（公开财报金额桥）**：

1. **B55 保持原义：** 只有存在真实的历史销量、净 ASP、单位变动成本时，才做 Shapley 量价成本归因；缺失就保持 UNKNOWN。
2. **金额桥另行计算：** 用审计年报 / 中期报告披露的营业收入、营业成本、销售费用、管理费用、研发费用、财务费用、投资收益、公允价值变动、减值、税费等实际金额，按报告会计口径建立公司整体利润表桥。
3. **避免成本重复：** 营业成本与营业费用按报表分类入账；营业成本中已经包含的制造折旧不再在后续步骤重复扣减。该金额桥不得伪装成单位变动成本。
4. **2026FY 预测使用“9M 实际 + Q4 情景”：** 已披露的 2026Q1-Q3 数字冻结为观察实际；只对 Q4 输入 Bear/Base/Bull 明确的分析假设，合成 FY2026。不可将九个月累计数直接与全年数当同期间比较。
5. **B57 继续单独核查：** 归母税后利润、少数股东归属、非经常项目和加权平均稀释股数逐项有来源或显式标成分析假设。任何假设分母必须显示为 ASSUMPTION_ONLY。
6. **B58/B60 不放宽：** 同预测期间、同币种、同分母之后才比较；B60 仍需要操作员现价和 15% 年化收益门槛。MIE 保持独立。

这条金额桥能先让没有公开物理销量的上市公司进入可解释的利润/EPS分析，同时不牺牲物理驱动路径的严格性。它不是用金额桥替代行业研究，而是承认不同公司公开披露粒度不同。

## 5. 本批非目标

本批不生成 2026FY Bear/Base/Bull 利润预测，不倒推加权平均稀释股数，不生成现价/目标价/Required Return EPS，不生成市场胜率，也不创建 BUY/ADD 决策。所有缺失项保持 UNKNOWN。
