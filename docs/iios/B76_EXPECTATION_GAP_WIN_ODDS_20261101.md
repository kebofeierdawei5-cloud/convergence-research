# B76 — 正预期差与胜率赔率研究链

日期：2026-11-01  
分支：`feat/b76-expectation-gap-win-odds-20261101`  
基线：B75 `2d11b3094e4d4f64661b0c91a6b9393aec7d4f6b`

## 目标

把现有 Round A 独立研究、B4–B68 盈利/估值传导、B61/B63 价格条件性反推和外部 MIE 严格区分，再用同一价格与持有期分析预期差、胜率、赔率和失败代价。B76 不新建估值或概率预测引擎。

## 本批改动

### 1. Round B Prompt

在现有 Round B 输入/输出边界内新增 B76 研究纪律：

- **独立预测**：基于冻结的 Round A 现实证据、主要矛盾、事件链和现有 B4–B68 传导。
- **价格条件性经营要求**：B61/B63 等在当前输入价格、持有期和收益/风险约束下的条件反推；标识为 `PRICE_CONDITIONED_REQUIREMENT`，不得称为外部市场共识。
- **外部 MIE**：只接受截止时点兼容、可核验的市场定价或一致预期证据；缺少证据仍为 `NOT_IDENTIFIABLE`。
- 将预期差拆为 `operating_gap`、`earnings_gap`、`valuation_gap`、`event_timing_gap`，分别比较经营变量、同期间归母净利润/EPS/FCF、可核验估值预期、事件兑现时间。
- 将 `win_odds` 放在现有 `assessment.expectation_gap` 对象内，分别承载胜率依据、赔率、上行/下行参照、失败代价、时间成本和催化窗口。
- 明确概率加权期望收益不等于胜率；Bear/Base/Bull 权重不天然等于投资胜率。若情景概率未校准，不得声称其为校准概率。
- 15% 年化门槛仍是新资金收益门槛，不是折现率；不输出正式资本动作，不改变估值或决策计算。

### 2. 报告呈现

在现有 MIE/预期差章节增加 B76 解释与可选子对象展示。缺失字段明确显示 UNKNOWN/未提供，不根据情景数值推导胜率，也不把价格条件性比较描述为市场预期差。

### 3. 回归断言

新增静态回归断言，检查 Round B Prompt 是否包含：
- 三种预期的区分；
- 四类预期差拆解；
- 胜率与情景概率的边界；
- 15% 收益门槛不是折现率。

并检查报告是否展示 B76 的边界说明和失败代价提示。

## 关键边界与未完成事项

- B61/B63 反推仍是价格/回报门槛条件性要求，不是 MIE。
- MIE 不可识别时，内部预测与价格条件要求的差异只能称为价格条件比较，不能称为已验证市场正/负预期差。
- B76 没有建立独立的胜率概率校准器，也没有将自由文本概率转换为机器认证概率。胜率缺乏证据时必须 UNKNOWN；不得把 Bull 概率当作胜率。
- 赔率与失败代价目前由研究者基于同一入场价/期限在 Round B 中论证；不擅自新增公式或覆盖既有 Return Metrics。
- 本地报告展示可选的结构化子对象，但它们是研究补丁内容，不代表证据已正式准入或结论已被系统独立验证。
- **已发现且明确保留的集成缺口：**当前 `_round_b_prompt_input` 会移除 `operator_valuation_context` 与 `decision_parameters`，Round B 发生在本地分析/回报计算之前，因此 B61/B63 已计算的价格条件性经营要求没有自动进入 Round B。故本批不能声称已完成 B61/B63 与独立预测的自动数值差额比较；缺少明确输入时必须 UNKNOWN。下一小步应审计 B61/B63 的真实输出 schema 与计算时序，再决定在 Round B 后增加只读对照呈现，或安全注入经计算的数值摘要；不得把人工上下文或反推值伪装成 MIE。
- 不修改 B4/B42/B43/B55 核心计算、SOTP、MIE 门禁、15% 门槛、目标入场价、组合约束、Decision 权限边界。
- 不修改 main，不合并 B73 历史分支。
